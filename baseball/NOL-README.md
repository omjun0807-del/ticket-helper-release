# NOL 야구 헬퍼 · 0.1.18

## 2026-11-02 한국시리즈

실제 사용자 Chrome에서 상품 번호 26014447, 제목 “2026 한국시리즈 1차전 KT vs 삼성”, h3 제목과 단일 disabled 카운트다운 버튼, 안내 “예매는 오픈 시간부터 가능해요”를 확인했습니다. 공식 NOL 목록에서 1차전 경기일 11월 3일 18:30, 예매 오픈 11월 2일 11:00(KST)를 확인했습니다. 경기 시작과 예매 오픈을 구분하세요.

한국시리즈 제목은 2026년 KT–삼성, 1~7차전으로 제한합니다. 공식 홈 일정에 맞춰 1·2·6·7차전은 KT vs 삼성, 3·4·5차전은 삼성 vs KT만 허용합니다. 다른 차전의 상품 번호와 개별 gate DOM은 아직 직접 확인하지 않았습니다. 기존 WC 1·2차전 LG–두산 인식도 유지합니다. 모든 공연으로 인식을 넓히지 않습니다.

## 오픈 준비 페이지 사용 순서

1. Tampermonkey에서 기존 “Ticket Helper - Ticketlink 경기 진입 시험판”을 업데이트합니다. 이름·namespace·설치/업데이트 주소는 유지합니다. 별도 구형 NOL 스크립트가 있으면 끄세요.
2. 대기열에 들어가기 전에 상품 페이지를 다시 로드하고 패널의 0.1.18을 확인합니다. 대기열(/waiting)에 들어간 뒤에는 새로고침하지 마세요.
3. ‘현재 상품 지정’을 누릅니다. 상품 번호·상품명은 현재 화면에서만 읽으며 직접 편집하지 않습니다. 1차전은 26014447 / 2026 한국시리즈 1차전 KT vs 삼성인지 확인하세요.
4. 예매 오픈 시각을 한국 PC 시각 기준 2026-11-02 11:00:00으로 입력하고 ‘상품 일치 확인’ 후 ‘시작 대기’를 누릅니다.
5. ‘화면 오픈까지 약 …초’ 문구와 PC 기준과의 차이를 확인합니다. 이 탭을 앞에 유지하고 영상에는 헬퍼 상태와 사이트 버튼을 함께 담으세요.
6. 열린 대기열·인증·안내·보안문자·좌석 선택은 직접 진행합니다.

시작 대기 때 단일 카운트다운을 읽으면 PC 현재 시각 + 남은시간으로 예상 오픈 시점을 계산합니다. 입력 시각과 2분 넘게 다르면 중지합니다. 읽지 못한 경우 PC 시각으로 기다립니다. 시작 후 PC 시간을 바꿨다면 중지 후 다시 시작하세요.

자동 새로고침 없이 기다리며, 지정한 상품 번호·상품명·차전·팀을 다시 확인합니다. 일치하는 단 하나의 활성 ‘예매하기’ 버튼만 1회 클릭합니다. 카운트다운 버튼 클릭·disabled 제거·연타는 하지 않습니다. 실행 상태를 소비한 뒤 클릭하며, 사용자가 먼저 클릭하면 자동 실행을 취소합니다. 상품 식별 정보가 바뀌거나 확인되지 않으면 즉시 중지합니다. 인증·보안문자·오류·대기열·오픈 기준 30초 만료·페이지 이탈에서도 종료합니다. 뒤로 돌아오면 타이머만 복원하고 사용자가 다시 시작해야 합니다.

## 목록 모드와 기존 기능

NOL 스포츠 목록에서는 경기 날짜·시작 시간·홈팀·원정팀·예매 오픈 시각을 입력하고 경기 버튼을 지정합니다. 지정 자체는 클릭하지 않습니다. 오픈 이후 단일 활성 버튼만 1회 클릭하며 자동 새로고침은 없습니다. 목록 설정은 gate 및 Ticketlink 설정과 분리합니다.

Ticketlink 기존 예매 진입과 안내 비교 진단은 보존합니다. NOL에는 안내 자동 확인 진단을 연결하지 않습니다. 기존 차단 기록도 보존합니다. 좌석 자동 선택·예약 제출·결제 자동화는 없습니다.

## 클릭 기록과 검증 한계

‘마지막 예매 버튼 클릭 기록’에는 같은 탭의 마지막 자동 클릭 또는 시작 대기 중 직접 클릭 1건만 남깁니다. version·kind·상품 번호·PC 기준 시각·실제 isTrusted 값만 저장합니다. 시작 전/중지 후/만료 후 클릭과 뒤이은 연타 전체는 기록하지 않습니다. 클릭 기록은 요청 성공·대기열 진입 성공을 의미하지 않습니다. 쿼리·쿠키·계정·pass_code·대기열 키는 수집하지 않습니다.

자체 패널의 CSS 속성으로 CSP 환경의 표시를 보완합니다. 페이지 CSP는 변경하지 않습니다. 실제 상품 DOM 확인, 합성 DOM 회귀 검사, PC 적용, 정각 자동 진입은 서로 다른 검증입니다. 0.1.18의 사용자 PC 적용과 실제 자동 진입 결과는 docs/baseball/TICKETING-LOG.md의 최신 기록을 확인하세요. 순번·좌석 확보·예매 성공을 보장하지 않습니다.
